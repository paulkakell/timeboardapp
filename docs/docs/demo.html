Deliberately public credentials

Demo mode displays known demonstration credentials on the login page and can periodically purge and rebuild demonstration data. This behavior is intentional for an isolated demo, not suitable for real users or private tasks. Never attach a production data volume or production integration secrets.

demo:
  enabled: true
  reset_interval_minutes: 360
  disable_external_apis: true

Keep outbound APIs disabled in public demonstrations. A reset interval of zero disables periodic resets but does not make the demo account private or safe for production. Data may also be reset through administrator tools.

What a demo can establish

A demo is useful for exploring boards, recurrence forms, calendar views, subtasks, and administrator pages. It does not establish that email, WNS, webhooks, a public ChatGPT integration, backups, or real-data recovery have been verified. Use a dedicated staging instance with controlled credentials for those acceptance tests.
