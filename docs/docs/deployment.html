Deployment and upgrades

Use an isolated, non-root application behind a trusted TLS proxy.

Source documentation — unreleased maintenance update

Reviewed September 26, 2026. Base application version 00.12.03. New security and ChatGPT behavior requires deploying the matching reviewed source; this site is not the task API.

Container boundary

The image runs as UID/GID 1000 by default. Compose uses the configured PUID/PGID, a read-only root filesystem, a writable data volume, a temporary filesystem, dropped Linux capabilities, and no-new-privileges. Pre-create the host data directory with matching ownership. The default published endpoint is loopback; explicitly configure the bind address and firewall when another host must reach it.

HTTPS and proxy trust

Set the public HTTPS application origin, preserve the Host header, and configure the proxy to forward the original scheme. Trust forwarded headers only from known proxy addresses. The application does not read arbitrary forwarded-proto headers to decide whether a response needs HSTS. Do not set Uvicorn's trusted proxy list to every address on an exposed server. Keep the internal application port 8888 unless you also adapt the image health check and Compose mapping.

Upgrade checklist

  1. Back up the complete SQLite database and settings while writes are stopped, or use a consistent SQLite backup procedure. Protect/encrypt copies: exports may contain password hashes and provider credentials.
  2. Restore the backup into a staging instance and run the complete regression workflow and local browser smoke test before production changes.
  3. Deploy the reviewed image. This update invalidates old JWTs and browser sessions: users must sign in again. Existing PBKDF2 passwords remain usable and migrate to Argon2id after successful login.
  4. Check data-volume permissions, health, login, task creation/completion, calendar, password reset, backups, and the configured notification providers. Reissue integration tokens after a JSON restore.
  5. Publish the matching docs only after reviewing the branch and confirming the deployment.

Rollback warning

The older application cannot verify newly migrated Argon2id passwords. Rolling back requires the matching pre-upgrade database/settings snapshot as well as the previous image; record and reconcile any tasks written after that snapshot. Do not treat an image-only rollback as sufficient.

Backups and credentials

Generated settings, initial credentials, and JSON backup files are written atomically with mode 0600. Protect the containing directory and external backup destination as well. Integration tokens are not included in JSON exports; recreate them after restore. Do not copy secrets into a GPT's instructions or a source-controlled OpenAPI file.

Operational limits

Use one application process for the built-in SQLite and background scheduler arrangement. Multi-worker/multi-replica operation needs coordinated scheduled jobs and a shared rate limiter. The application limiter is bounded but process-local; add reverse-proxy rate limits and request timeouts. Monitor notification errors rather than assuming configured providers have delivered a message.
