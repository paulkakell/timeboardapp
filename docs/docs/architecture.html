Architecture and features

A task application with a deliberately narrow assistant integration.

Source documentation — unreleased maintenance update

Reviewed September 26, 2026. Base application version 00.12.03. New security and ChatGPT behavior requires deploying the matching reviewed source; this site is not the task API.

Runtime

FastAPI serves JSON routes and server-rendered Jinja templates; SQLAlchemy manages SQLite; APScheduler runs retention, backup, reminder, and demo jobs. UI sessions use signed cookies and database credential-state checks. Asynchronous notification dispatch keeps provider requests out of the main task write path. Bootstrap and FullCalendar assets are npm-locked, vendored with license notices, and served locally.

Task features

Task boards and calendar views support active/archived status, tags, searching, task-type filters, sorting, and per-user preferences. Nested subtasks, cloning, administrator views, manager assignment, task following, and in-app notifications remain supported. Closing a parent requires closing descendants or confirming a cascade in the UI.

Recurrence

Post-completion intervals schedule relative to completion; multi-slot daily schedules use configured clock times; fixed-clock schedules follow anchored intervals or supported calendar rules. Examples include 8h, 08:00,15:00,23:00, and Every Tuesday. Internal stored dates are UTC; display uses the configured application timezone. Complex recurring-subtree recovery after an interrupted write still deserves operational restore testing.

Notification capabilities

Browser notifications use server-sent events while the page is connected; this is not offline Web Push. Email supports SMTP and SendGrid. Discord, webhook, generic API, Gotify, and ntfy use configured delivery endpoints subject to the outbound policy. WNS code implements the legacy UWP credential model and requires a compatible Windows client/channel; it is not a modern Windows App SDK integration. No provider is considered live-verified merely because its adapter passed mocked tests.

Compatibility decisions

Bootstrap is updated within 5.3. FullCalendar stays on the latest verified 6.1 patch line rather than silently moving to the breaking v7 API. The scheduler stays within APScheduler 3. Browser assets no longer require a runtime CDN, except the optional FastAPI documentation viewer. The generated route/package reference is checked against source to reduce website drift.

Assistant boundary

A separate ChatGPT Actions router exposes owner-only task operations, not the administrator or notification-management surface. Personal access tokens use a separate credential type and narrow read/write scopes. Native MCP, per-user OAuth consent, and arbitrary model-serving endpoints are outside this implementation.
